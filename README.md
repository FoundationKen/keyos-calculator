# Calculator

A basic and scientific calculator for KeyOS firmware 1.4.0 or later, built with
Foundation SDK v1.1.0.

## Release Build

On macOS, double-click `Build Release.command` in Finder. It selects the installed
SDK v1.1.0, enters its Nix environment, and runs `foundation build --release`.
The SDK's normal installation location under `~/.foundation/sdk/` is required.

The signed application bundle is written to `target/keyos/Calculator/`.
The build does not upload to or launch on a device.

Dependencies use the ignored `.foundation-sdk/current` mapping generated by the
Foundation CLI. The release script selects v1.1.0 independently of the globally
active SDK. Running Foundation commands directly uses the SDK selected by that
shell; `foundation build` and `foundation sideload` require `--release` to select
the release profile.

## Tests

After the first build, run `cargo test --locked` inside the SDK v1.1.0 Nix shell.
The Cargo configuration resolves the generated UI and themes from this app's
`target/foundation/` directory.
